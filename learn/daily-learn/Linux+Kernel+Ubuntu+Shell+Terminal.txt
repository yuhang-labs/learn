第1天｜第一阶段：Linux 与系统诊断

知识点：
Linux、Kernel、Ubuntu、Shell、Terminal


定义：

1. Linux

Linux 是一种操作系统生态，负责管理计算机硬件资源，并为应用程序提供运行环境。

Linux主要负责：

- CPU管理
- 内存管理
- 文件系统管理
- 网络管理
- 设备管理
- 进程管理


2. Kernel（内核）

Kernel 是 Linux 系统最核心的软件层。

它负责直接管理：

- CPU
- 内存
- 硬件设备
- 驱动程序
- 文件系统
- 网络协议

Kernel 是应用程序和硬件之间的桥梁。


3. Ubuntu

Ubuntu 是 Linux 的一种发行版。

Linux Kernel 提供底层能力，Ubuntu 在其基础上提供：

- 软件管理
- 系统工具
- 用户环境
- 开发环境

机器人开发中常使用 Ubuntu，因为：

- ROS 官方支持好
- 驱动丰富
- 工具完善


4. Shell

Shell 是用户和操作系统交互的命令解释器。

用户输入命令：

命令 → Shell解析 → Kernel执行 → 返回结果


常见Shell：

- bash
- zsh
- fish


5. Terminal

Terminal 是终端窗口。

它提供：

- 输入Shell命令
- 显示执行结果

Terminal本身不会执行命令，它只是Shell的操作入口。

为什么需要Linux？

机器人系统需要：

- 多任务运行
- 硬件访问
- 网络通信
- 驱动支持
- 系统调试

例如机器人同时运行：

- 摄像头节点
- 激光雷达节点
- CAN通信节点
- 导航节点
- 控制节点

Linux可以统一管理这些资源。

应用程序不能直接控制硬件。

Debug 第一检查点：

第一步：

确认问题现象。

例如：

错误：

摄像头坏了。


正确：

摄像头节点启动，但是没有图像。


第二步：

确认系统状态。


查看设备：

lsusb


查看进程：

ps aux


查看日志：

journalctl


第三步：

缩小问题范围。


判断：

- 软件问题
- 配置问题
- 驱动问题
- 硬件问题


------------------------------------------------------------

测试关注点：

1. 正常测试：

验证系统正常运行。


例如：

网络：

ping目标地址


2. 异常测试：

模拟：

- 断电
- 断网
- 拔设备


观察系统行为。


3. 恢复测试：

验证：

设备重新连接后是否恢复。


4. 边界测试：

测试：

- 高CPU
- 大数据量
- 网络延迟
- 资源不足
