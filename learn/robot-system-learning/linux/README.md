# day1学习记录
/是系统根目录
home 存放用户个人文件
etc 系统配置文件目录，系统设置中心
var 变化数据目录
usr 用户程序目录（系统安装的程序目录）
opt 安装额外的软件
tmp 临时数据目录
dev 设备文件目录（硬件设备）
| 目录      | 作用    | 机器人开发例子          |
| ------- | ----- | ---------------- |
| `/`     | 根目录   | 整个系统             |
| `/home` | 用户文件  | 代码、工程            |
| `/etc`  | 系统配置  | 网络、服务、启动         |
| `/var`  | 变化数据  | 日志、缓存            |
| `/usr`  | 系统软件  | python、git、ros工具 |
| `/opt`  | 第三方软件 | CUDA、ROS         |
| `/tmp`  | 临时文件  | 编译缓存             |
| `/dev`  | 设备文件  | 串口、摄像头、磁盘        |
