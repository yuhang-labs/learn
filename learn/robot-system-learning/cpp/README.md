## 3. 重点理解

### 数组

- 数组是一组类型相同、按顺序存放并通过下标访问的元素。
- C++ 数组示例：`int array[5] = {0, 1, 3, 6, 7};`。
- 第一个元素的下标是 `0`，因此 `array[0]` 的值是 `0`，`array[3]` 的值是 `6`。
- 遍历长度为 5 的数组时，下标范围是 `0` 到 `4`，循环条件可写成 `i < 5`。

### 循环、判断和取模

- `for` 的三部分是初始化、继续循环的条件和每轮结束后的更新。
- `if` 条件成立时执行对应分支，否则执行 `else` 分支。
- `%` 是取模运算，得到整数除法的余数。例如 `5 % 2` 等于 `1`。
- 一个整数对 2 取模为 0 时是偶数，否则是奇数。

### 函数

- 函数把一段明确的逻辑封装起来，方便调用和复用。
- `sum(int a, int b)` 中，`a` 和 `b` 是输入参数，`return a + b` 返回计算结果。
- `total += i` 等价于 `total = total + i`。
- 当前程序中的 `main()` 没有参数，`return 0` 表示程序正常结束。

## 4. 遇到的问题与纠正

### `cout` 和 `endl` 未声明

- 报错原因是程序使用了 `cout` 和 `endl`，但最初没有包含 `<iostream>`，或者没有使用正确的命名空间。
- 当前程序使用 `#include <iostream>` 和 `using namespace std;` 后能够正常编译。
- 也可以不写 `using namespace std;`，改用 `std::cout` 和 `std::endl`。

### `g++ day3_func.cpp day3_func` 链接失败

- 该命令没有使用 `-o`，因此 `g++` 把 `day3_func` 当成另一个输入文件查找。
- 正确命令是 `g++ day3_func.cpp -o day3_func`。
- `-o day3_func` 用于指定生成的可执行文件名称。
