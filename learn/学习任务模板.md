学习清单如下。

1. Linux 基础强化：文件、目录、权限、常用命令
目标：进一步熟悉 Linux 文件系统和命令行操作。

任务 1：熟悉 ls 的详细用法
- 练习命令：
  - ls -la
  - ls -lh
  - ls -lt
  - ls -a
- 重点理解：
  - -a 显示隐藏文件
  - -l 显示详细信息
  - -h 人类可读大小
  - -t 按修改时间排序
- 验证：
  - 你能解释每列内容的含义
  - 能区分普通文件、目录、可执行文件

任务 2：文件/目录创建与复制
- 练习命令：
  - mkdir -p /home/buff/Workspace/learn/robot-system-learning/linux/day2-demo/subdir
  - touch /home/buff/Workspace/learn/robot-system-learning/linux/day2-demo/a.txt
  - echo "hello day2" > /home/buff/Workspace/learn/robot-system-learning/linux/day2-demo/a.txt
  - cp a.txt backup.txt
  - mv backup.txt renamed.txt
- 验证：
  - 目录结构清晰
  - 你能说出 cp 与 mv 的区别
  - 你能解释 文件覆盖/重命名 的含义

任务 3：查看文件内容与筛选
- 练习命令：
  - cat a.txt
  - head -n 5 a.txt
  - tail -n 5 a.txt
  - grep "day2" a.txt
  - wc -l a.txt
- 验证：
  - 能理解 cat/head/tail/grep/wc 的用途
  - 能说出 “过滤日志”和“查看文件头尾”的差别

任务 4：权限管理
- 练习命令：
  - chmod 755 demo.sh
  - chmod 644 a.txt
  - ls -l a.txt demo.sh
- 重点理解：
  - r w x
  - 读、写、执行权限
  - 7/5/4 的含义
- 验证：
  - 能解释一个文件为什么不能执行
  - 能说出 chmod 的作用

任务 5：查找文件
- 练习命令：
  - find . -name "*.txt"
  - find . -type f | head
- 验证：
  - 能说明 find 的常用场景
  - 能说出 find 与 ls 的区别

2. Shell 基础：脚本与环境变量
目标：第一次写 Shell 脚本，理解脚本执行方式。

任务 6：创建简单脚本
- 在 `robot-system-learning/linux/` 中创建脚本：
  - nano day2_demo.sh
  - 或使用 echo > day2_demo.sh
- 内容示例：
  - #!/bin/bash
  - echo "Today is $(date)"
  - name="robot"
  - echo "Hello $name"
  - echo "Current path: $PWD"
- 运行：
  - chmod +x day2_demo.sh
  - ./day2_demo.sh
- 验证：
  - 脚本能成功执行
  - 能解释 $PWD、$name、$(date) 的意义

任务 7：条件判断与循环
- 写一个脚本：
  - if [ -f "a.txt" ]; then echo "file exists"; else echo "missing"; fi
  - for i in 1 2 3; do echo $i; done
- 验证：
  - 能理解 if 条件判断
  - 能理解 for loop 的语法

任务 8：重定向与管道
- 练习命令：
  - echo "hello" > out.txt
  - ls | head
  - ls > files.txt
  - cat files.txt
- 验证：
  - 能说明 > 和 >> 的不同
  - 能理解 管道 | 的作用
  - 能解释 “把前一个命令的输出传给后一个命令”

3. Git 基础强化
目标：熟悉日常开发中最重要的版本控制流程。

任务 9：查看状态和差异
- 练习命令：
  - git status
  - git diff
  - git diff --staged
- 验证：
  - 能解释 untracked / modified / staged 的含义
  - 能说出 git diff 和 git status 的区别

任务 10：提交与历史
- 练习命令：
  - git add robot-system-learning/linux/day2_demo.sh
  - git commit -m "day2: add linux shell practice"
  - git log --oneline -n 5
- 验证：
  - 能说明 commit 的意义
  - 能解释每次提交记录适合放什么内容

任务 11：回退与恢复
- 练习命令：
  - echo "temporary change" >> somefile
  - git checkout -- somefile
  - 或 git restore somefile
- 验证：
  - 你知道如何恢复未提交修改
  - 能说出 git restore 和 git checkout 的用途

4. C++ 入门：变量、输入输出、函数
目标：从 “编译运行” 走向 “写基础 C++ 程序”。

任务 12：基本输出和变量
- 新建：
  - `robot-system-learning/cpp/`
- 文件：
  - hello_day2.cpp
- 内容示例：
  - #include <iostream>
  - using namespace std;
  - int main() {
      int a = 10;
      double b = 3.14;
      string name = "robot";
      cout << "a = " << a << endl;
      cout << "b = " << b << endl;
      cout << "name = " << name << endl;
      return 0;
    }
- 编译：
  - g++ hello_day2.cpp -o hello_day2
  - ./hello_day2
- 验证：
  - 输出能正常显示
  - 能解释 int、double、string 的类型

任务 13：输入输出和条件判断
- 文件：
  - condition.cpp
- 内容：
  - #include <iostream>
  - using namespace std;
  - int main() {
      int score;
      cout << "input score: ";
      cin >> score;
      if (score >= 60) cout << "pass" << endl;
      else cout << "fail" << endl;
      return 0;
    }
- 编译与运行：
  - g++ condition.cpp -o condition
  - ./condition
- 验证：
  - 输入 60 会输出 pass
  - 输入 50 会输出 fail

任务 14：函数基础
- 文件：
  - add.cpp
- 内容：
  - int add(int a, int b) { return a + b; }
  - int main() { cout << add(3, 5) << endl; }
- 验证：
  - 能说出函数为什么有用
  - 能说出参数、返回值的作用
